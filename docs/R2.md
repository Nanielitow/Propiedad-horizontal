# Archivos en Cloudflare R2 (producción)

Los PDF, soportes de recaudos, evidencias de mantenimiento y adjuntos del portal se guardan en un
almacenamiento compatible con S3. En local es SeaweedFS (Docker); en producción, **Cloudflare R2**: sin cobro
por descarga (egress), 10 GB gratis al mes y después ~US$0,015 por GB-mes. Hoy los archivos de la demo ocupan
menos de 1 MB.

El navegador sube (PUT) y lee (GET) los archivos **directamente** del almacenamiento con URLs firmadas que
expiran en 5 minutos: la API nunca transmite el PDF y el bucket nunca es público.

## Compatibilidad

- `region_name="auto"` y direcciones de estilo *path* (`https://<cuenta>.r2.cloudflarestorage.com/<bucket>/<clave>`).
- boto3 ≥ 1.36 manda sumas de verificación CRC en cada petición y R2 rechaza algunas: el cliente usa
  `request_checksum_calculation="when_required"` (`app/services/storage/s3.py`), que también funciona con
  SeaweedFS y S3.
- El CORS se configura en el panel de Cloudflare, porque el token de la aplicación solo puede leer y escribir
  objetos (principio de mínimo privilegio).

## Pasos en Cloudflare (los hace el dueño de la cuenta)

1. **Activar R2**: panel de Cloudflare → *R2 Object Storage* → activar (pide un medio de pago aunque se quede
   en la capa gratis).
2. **Crear el bucket** `ph-documentos`: ubicación automática, clase de almacenamiento *Standard*. **No**
   activar el acceso público ni el dominio público.
3. **CORS del bucket**: bucket → *Settings* → *CORS Policy* → *Add CORS policy* → pegar:

   ```json
   [
     {
       "AllowedOrigins": ["https://app.propiedadhorizontal.app", "http://localhost:3000", "http://localhost:3001"],
       "AllowedMethods": ["GET", "PUT", "HEAD"],
       "AllowedHeaders": ["content-type", "range"],
       "ExposeHeaders": ["ETag", "Content-Length", "Content-Range", "Accept-Ranges"],
       "MaxAgeSeconds": 3600
     }
   ]
   ```

4. **Token de la aplicación**: R2 → *Manage API tokens* → *Create API token* → permiso **Object Read &
   Write**, **solo el bucket `ph-documentos`**, sin vencimiento (o con recordatorio de rotación). Cloudflare
   muestra **una sola vez** el *Access Key ID*, el *Secret Access Key* y el endpoint
   `https://<ID de cuenta>.r2.cloudflarestorage.com`.
5. Pegar los tres valores en `.env` (`R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`), entre
   comillas. **Nunca en el chat ni en Git.**

## Copia y cambio

`deploy/r2/copiar.py` copia los archivos del bucket local de la demo a R2 (idempotente, sin imprimir
credenciales) y verifica clave por clave que estén todos con el mismo tamaño. Después la demo pasa a usar R2 y
el bucket local `ph-demo` y la ruta `archivos.propiedadhorizontal.app` del túnel dejan de hacer falta.
